# Быстрая проверка

Проверка плана, не реализация. Команды каркаса уже есть. Значение `sKey` сюда не пишется: его задают только в браузере.

## Подготовка

```bash
npm install
npm run lint
npm test
npm run dev
```

Открыть адрес Vite (обычно `http://localhost:5173/`).

## Сценарии приёмки плана

1. **Пустой старт / сид**  
   Если IndexedDB пуст, список берётся из `{VITE_BASE}data/companies.json`. После первой загрузки правки живут в IndexedDB. Пока пользователь явно не импортирует файл и не сбросит к сиду, деплой сайта не затирает рабочую копию.

2. **CRUD (история 1)**  
   Добавить компанию: имя обязательно; сайт и email — если заполнены, то валидны. Открыть карточку, изменить, сохранить. Удалить с подтверждением. Перезагрузить вкладку — данные на месте.

3. **Письмо (история 2)**  
   Две компании, разные тексты в textarea. Письма не смешиваются после перезагрузки. Копирование — выделение в поле, без кнопки.

4. **Ручные вакансии и хардкод-фильтр (история 3)**  
   В форме указать название и URL вакансии. В карточке — гиперссылка. Включить фильтр — остаются совпадения со **встроенным** набором; редактора слов нет. Выключить тумблер — полный сохранённый список (SC-004). Компания без ссылок не ломает экран.

5. **Ключ `sKey` и публичный файл (FR-019)**  
   В `localStorage` выставить ключ **именем** `sKey` (поле приложения или инструменты браузера). Значение не копировать в репозиторий.  
   - Ключа нет: компании/email/вакансии из файла видны; письмо из файла не расшифровывается и не показывается, даже если в JSON что-то есть.  
   - Ключ есть и конверт верный: в карточке открытый текст.  
   - Экспорт при отсутствии ключа не записывает открытые письма в скачанный файл.

6. **Импорт / экспорт (история 5)**  
   Экспорт — JSON той же схемы (письма в файле зашифрованы либо пустые). Импорт валидного файла заменяет рабочую копию. Битый файл — ошибка, старые данные целы. Агент может наполнить `public/data/companies.json` без кликов по UI. Сброс к файлу сайта — отдельное явное действие, не часть обычного импорта.

7. **Не облако**  
   В UI и README есть короткая фраза: данные в этом браузере, это не облачная база.

8. **Сборка Pages**

```bash
npm run build
npm run preview
```

Приложение открывается с базой `/job_searching/`. Есть `dist/404.html` и `dist/data/`. В `dist/data/companies.json` нет открытых писем и нет значения `sKey`.
