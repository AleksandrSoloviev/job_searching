# Быстрая проверка

Проверка плана. Команды каркаса уже есть.

## Подготовка

```bash
npm install
npm run lint
npm test
npm run dev
```

Открыть адрес Vite (обычно `http://localhost:5173/`).

## Сценарии приёмки плана

1. **Пустой старт / сид**  
   Если IndexedDB пуст, список и таблица берутся из `{VITE_BASE}data/companies.json`. После первой загрузки правки живут в IndexedDB. Пока пользователь явно не импортирует файл и не сбросит к сиду, деплой сайта не затирает рабочую копию.

2. **CRUD и таблица (история 1)**  
   Добавить компанию: имя обязательно; сайт и email — если заполнены, то валидны. В таблице клик по имени открывает карточку; сайт, email и вакансии — ссылки. Письмо видно в подсказке строки, не колонкой. Открыть карточку из компактного списка, изменить, сохранить. Удалить с подтверждением. Перезагрузить вкладку — данные на месте.

3. **Письмо (история 2)**  
   Две компании, разные тексты в textarea. Письма не смешиваются после перезагрузки. Копирование — выделение в поле, без кнопки. В таблице письмо той же компании в tooltip.

4. **Ручные вакансии и хардкод-фильтр (история 3)**  
   В форме указать название и URL вакансии. В карточке и в таблице — гиперссылка. Включить фильтр — остаются совпадения со **встроенным** набором, **без** React Native / `react-native` / слова `RN`; редактора слов нет. Выключить тумблер — полный сохранённый список (SC-004). Компания без ссылок не ломает экран. Таблица и список текущей страницы идут от известных (`fameRank` меньше) к менее известным; без поля — в конце. Импорт JSON добавляет новую страницу; сид/сброс — страница 1.

5. **Публичный файл (FR-019)**  
   `coverLetter` в сиде, импорте и экспорте — обычная строка. Поля ключа и шифрования нет.

6. **Импорт / экспорт (история 5)**  
   Экспорт — JSON той же схемы (письма как есть). Импорт валидного файла заменяет рабочую копию. Битый файл — ошибка, старые данные целы. Агент может наполнить `public/data/companies.json` без кликов по UI. Сброс к файлу сайта — отдельное явное действие.

7. **Не облако**  
   В UI и README есть короткая фраза: данные в этом браузере, это не облачная база.

8. **Сборка Pages**

```bash
npm run build
npm run preview
```

Приложение открывается с базой `/job_searching/`. Есть `dist/404.html` и `dist/data/`.
