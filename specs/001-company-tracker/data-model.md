# Модель данных

Канон полей — `spec.md` (модель данных + FR-012…FR-019). Здесь — правила для файла и рабочей копии. Файл, импорт, экспорт и IndexedDB используют одну и ту же форму: `coverLetter` — обычная строка.

## Каталог

Версионированный снимок. Одна схема для файла сайта, импорта и экспорта.

| Поле | Тип | Правила |
|------|-----|---------|
| schemaVersion | string | Обязательно. Мажор `1` совместим. Иначе отказ загрузки/импорта. Текущее значение `1.0.0`. |
| companies | Company[] | Плоский снимок (сид, GrokBot). Пустой допустим. При загрузке без `pages` становится одной страницей. Дубли `id` внутри страницы: последняя запись побеждает. |
| pages | Page[] | Рабочая копия и экспорт приложения. Каждая страница — батч компаний. |
| activePageIndex | number | Открытая страница (clamp). |

## Компания

| Поле | Тип | Файл / импорт-экспорт / IndexedDB | Правила |
|------|-----|-----------------------------------|---------|
| id | string | да | Обязателен, непустой, стабильный |
| name | string | да | Обязателен, непустая строка |
| website | string | да | Пусто или URL |
| email | string | да, открытый текст | Пусто или email |
| coverLetter | string | обычная строка, можно `""` | см. «Письмо» |
| fameRank | number? | да (опц.) | Меньше — известнее (выше в таблице и списке). Нет поля — в конец. Не мировой рейтинг. |
| vacancies | Vacancy[] | да | Можно `[]` |
| vacanciesSource | string? | да (опц.) | В v1 не запускает API |
| updatedAt | string? | да (опц.) | ISO-время, если задано |

## Вакансия

| Поле | Тип | Правила |
|------|-----|---------|
| id | string | Обязателен внутри компании |
| title | string | Обязателен; участвует в фильтре |
| url | string | Обязателен в схеме файла. Без валидного URL не показывать как рабочую гиперссылку |
| publishedAt | string? | Необязательно |
| summary | string? | Участвует в фильтре |
| lastAppliedAt | string | Пусто или календарная дата `YYYY-MM-DD`. Относится к вакансии, не к компании. |

Основной путь появления вакансии — ручной ввод `title` + `url` в форме. Файл/импорт MAY принести готовый массив.

## Письмо

- `coverLetter` — открытый текст, который пользователь видит, правит и видит в подсказке таблицы.
- Та же строка в файле сайта, импорте, экспорте и IndexedDB.
- Пустое намерение → `coverLetter: ""`.
- Шифрования нет: конверта нет, ключа нет.
- Привязка строго к `id` компании (история 2; SC-002).

## Фильтр вакансий (не сущность хранения)

Встроенный набор — константа кода (список в [research.md](./research.md)). Не пишется в каталог и не редактируется в UI. Состояние экрана — булев флаг «фильтр включён». Совпадение: любое слово набора как подстрока без регистра в `title` или `summary`. При включённом фильтре роли React Native скрываются: фразы `react native` / `react-native` / `реакт нейтив` и отдельное слово `RN` (не подстрока вроде intern).

## Сортировка компаний (не сущность хранения)

Показ таблицы и бокового списка **текущей страницы**: по `fameRank` по возрастанию, затем имя (`localeCompare` ru). Отсутствующий `fameRank` считается «менее известной» и идёт в конец. Порядок в JSON не обязан совпадать с порядком на экране.

## Страницы каталога

| Поле | Тип | Правила |
|------|-----|---------|
| pages | Page[] | Батчи компаний. При разборе плоского `{ companies }` создаётся одна страница. Пустой `pages` при наличии `companies` не используется. |
| activePageIndex | number | Открытая страница. Вне диапазона — clamp. |
| page.id | string | Стабильный id страницы |
| page.companies | Company[] | Компании этой страницы; дубли `id` внутри страницы схлопываются |

Импорт плоского JSON в уже открытый каталог **дописывает** новую страницу. Экспорт пишет все `pages`. Сброс к файлу сайта заменяет рабочую копию одной страницей сида.

## Состояния каталога

- **Нет рабочей копии** → загрузить публичный сид как есть; если сид недоступен — пустой каталог.
- **Есть рабочая копия** → сид не применять, пока нет явного импорта или сброса.
- **Импорт** → файл целиком валиден или отказ; при ошибке рабочая копия не меняется. Успешный плоский импорт **добавляет страницу**, не заменяет каталог.
- **Сброс к файлу сайта** → рабочая копия = одна страница сида (страница 1).
- **Удаление компании** → запись исчезает с текущей страницы.

## Валидация на границе

- Неизвестные поля отбрасываются (Zod strip), загрузка совместимой схемы не ломается.
- Нет `schemaVersion`, пустой `name`/`id`, мажор ≠ 1, невалидный непустой сайт/email, вакансия без обязательных полей → отказ всего файла.
- Нехватка квоты IndexedDB → ошибка пользователю, без тихой обрезки писем.
